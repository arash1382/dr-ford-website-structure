# Interaction Specification

- Logo links to home; navigation links to real pages or valid section anchors.
- Mobile menu opens/closes predictably.
- Language switcher changes text and `lang`/`dir`, not just alignment.
- Course cards link to real detail pages or explicitly identified placeholders.
- Founder gallery uses approved names/photos, alt text, touch, and keyboard support.
- Partner carousel uses approved logos and preserves their proportions. Omit it until logos are available.
- Statistics use verified figures only; otherwise omit the section or mark development placeholders.
- FAQ uses semantic buttons and accessible expanded/collapsed states.
- Forms have labels, validation, clear success/error feedback, and must not claim submission unless a backend is connected.
- No `href="#"` dead links or inert buttons.
- Respect reduced-motion settings.

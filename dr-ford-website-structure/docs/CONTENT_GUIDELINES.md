# Content Guidelines

Visitors should quickly understand what Dr. Ford is, what learning options exist, how private courses work, where/when courses take place when confirmed, and how to contact or register.

## Inputs needed
- Approved school description
- Course names, descriptions, audience, format, dates, venues, prices if applicable
- Registration process and contact details
- Founder names, roles, portraits, biographies
- Approved partner logos and names
- Publishable project descriptions and verified outcomes
- Verified impact metrics and FAQ answers

## Accuracy
Never invent names, organizations, statistics, testimonials, schedules, locations, prices, or results. Mark development placeholders clearly and replace or remove them before launch.

## CTA hierarchy
Primary: Explore courses / View courses
Secondary: Learn about Dr. Ford
Contextual: View course details, Ask about a private course, Register, Contact us

Write naturally in Persian and English. Check Persian spelling, نیم‌فاصله, punctuation, and consistent terminology.

# Design System

## Tokens
| Token | Hex | Purpose |
|---|---|---|
| Background | `#080A09` | Main canvas |
| Background secondary | `#101411` | Alternate sections |
| Surface | `#171B18` | Cards and elevated UI |
| Text | `#F5F7F5` | Main copy |
| Text secondary | `#A8AEA9` | Supporting copy |
| Accent | `#B7FF00` | CTAs and active states |

## Typography
Use official Persian and English font files when supplied. Until then, centralize readable fallback font declarations. Keep Persian line-height comfortable and use correct RTL layout.

## Layout
Use a consistent spacing scale based on multiples of 4, a responsive grid, generous negative space, readable line lengths, and consistent content widths. Avoid boxing every section into cards.

## Components
Header, mobile navigation, buttons, course card, event card, statistics counter, founder profile, partner carousel, FAQ accordion, contact/registration form, footer, language switcher.

## Responsive and accessible behavior
Test desktop, tablet, and mobile. Prevent horizontal overflow. Provide visible focus states, keyboard-accessible controls, sufficient contrast, and reduced-motion support.

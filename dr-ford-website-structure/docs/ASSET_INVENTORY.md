# Asset Inventory

Suggested folders:
```text
public/
├── logo/
├── fonts/persian/
├── fonts/english/
├── images/hero/
├── images/founders/
├── images/projects/
├── images/partners/
├── videos/
└── icons/
```

| Asset | Priority | Notes |
|---|---|---|
| Official logo, preferably SVG | High | Preserve proportions and geometry |
| Persian font files | High | Confirm weights and license |
| English font files | High | Confirm weights and license |
| Founder portraits and approved names | Later | Use only authorized material |
| Partner logos | Later | Use approved logos only |
| Course photos | Optional | Real imagery preferred |
| Project images | Optional | Publishable material only |
| Hero video | Optional | Must not delay access to content |
| Favicon | Before launch | Derive from official logo if permitted |

Use descriptive filenames and optimize images. Never commit API keys, tokens, private data, or confidential client materials.

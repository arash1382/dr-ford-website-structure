# Dr. Ford Website

Documentation pack for building the Dr. Ford AI School website in Google AI Studio Build Mode.

## Start here
1. Keep these Markdown files in your GitHub repository.
2. Open `AI_STUDIO_PROMPT.md` and paste it into Google AI Studio Build Mode.
3. Add the real logo, fonts, photos, and other approved assets when available.
4. Build the homepage first; use `docs/PROJECT_ROADMAP.md` for the next steps.

The website serves both individuals and organizations. Never invent course details, founders, partner brands, statistics, or testimonials.
